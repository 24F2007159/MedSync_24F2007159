# MedSync - Hospital Management System

A web-based Hospital Management System built for MAD-I (Modern Application Development I).

## Roles
- Admin: Manages doctors, patients and appointments
- Doctor: Views appointments and updates treatment records
- Patient: Books appointments and views medical history

## Tech Stack
- Backend: Flask, SQLAlchemy, SQLite
- Frontend: Vue.js, Bootstrap

## Setup
cd backend
python app.py
